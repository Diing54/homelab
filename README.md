# Home Lab

This repository documents a self-hosted home lab built using:
- Raspberry Pi (Ubuntu Server) as a production node
- Two laptops as admin and client nodes (both running arch linux)

## Objectives
- Practice real-world networking and Linux administration
- Implement secure access patterns (SSH, firewalls)
- Build internal DNS and service routing
- Observe and troubleshoot system behavior
- Document decisions and failures like a production system

## Roles
- **Raspberry Pi**: Production server
- **Laptop A**: Admin / Bastion
- **Laptop B**: Client / User
